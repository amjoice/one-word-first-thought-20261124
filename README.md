## What it is

`main.py` is a small, pure-stdlib Python program that writes exactly one word
to `/output/entry.txt`: **borborygmus** — the rumble of a hungry stomach.
No network, no randomness, no input files. Two runs write identical bytes.

Why this word: it is rare enough to surprise, vivid enough that every reader
feels it at once, and it carries its own wit in its sound — the word itself
rumbles like the thing it names.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
